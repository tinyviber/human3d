# ADR-0004：标量通道切线限界 κ=2·min 割线；手部朝向 corrected-slerp SO(3) 三次

状态：已确认（WP-C 两提交）。数值证据、迁移 delta 表与探针对照见 [../history/investigate.md](../history/investigate.md)「WP-C」三节。

## 决定

- 内部键切线限界 `|m| ≤ κ·min(|s左|, |s右|)`，`κ = TANGENT_SECANT_CAP = 2`，方向对称、保号；端点切线为 0；rest/锁定通道零切线约定不破；每键单一切线值 → C¹ 保持。
- 手部朝向由逐段 slerp 改为 corrected-slerp 形式的 SO(3) 三次曲线：`q(u) = slerp(q_i,q_{i+1},u)·exp(u(1−u)(d0+u·d1))`；过键逐位精确（≤7.3e-16）、键时刻角速度 C¹；切线构造与标量 `tan()` 同为按时间的中心差分；loop 幽灵链每侧两个周期拷贝，与 `tan()` 同构。
- 整条四元数链（含 loop 幻影）先做 dot<0 符号连续再算割线——链级半球处理，不做逐段端点修号。

## 被否方案 / 对评审原案的偏离（均有实测依据）

- **切线帽取 `max` 相邻割线（评审原案写法）**：中心差分两割线加权均值的幅值必落在两割线区间内，`max` 帽数学上永不触发（实测全零）；致病机制是快邻域切线被施加到慢区间，故界取 `min`。
- **字面 Shoemake 双 slerp squad**：`slerp(slerpAB, slerpCD, 2u(1−u))` 在本仓库稀疏大旋转键（≥90°/0.15s）下内控制链与弦近反向（dot 最深 −0.925），外层 slerp 半球选择中途切换造成真实跳变（采样 ω ~6275 rad/s），比被修缺陷更糟——采用有界相对旋转增量的修正式。
- **κ ≤ 1.5 / κ ≥ 3**：κ 校准表（240fps 探针 + 通道级过冲直接度量）显示 κ=2 砍掉稀疏文档约 ⅓ 过冲且对密集文档扰动 ≤1.12mm/0.112°；更小界会抹平真实加速，更大界交付不足。
- **腕锥限位拓宽**：`WRIST_BEND_LIMIT_DEG` 维持 59.8°——超限是种子文档自身需求，不是限幅过紧的证据。

## 诚实边界

钳制界住的是**通道层位移过冲**；求解骨角速度峰值由求解器主导（能量迁移而非消失），回归断言锚在通道层。逐位细节见 history。
